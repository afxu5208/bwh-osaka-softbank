简单说，如果你是联通或移动用户，主要面向亚洲访客，JPOS_1 是个很靠谱的选择。如果你是电信用户且对线路稳定性要求极高，可能需要对比一下 CN2 GIA-E 的洛杉矶 DC6 机房再做决定。
